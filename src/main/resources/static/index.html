Intermediario de Pólizas

Sistema cliente-servidor para distribuir información de pólizas de seguro. Arquitectura de Software 302, 2026-II.

Pólizas

Gestionar póliza (PRM-GP) no tiene una ruta propia: se realiza con las operaciones de póliza de esta sección. La clave es el identificador de la póliza y no se modifica.

Clientes

La CURP identifica el registro del cliente y no se modifica. En la modificación, los campos vacíos no se tocan.

Beneficiarios

El beneficiario debe ligarse a una póliza que exista. Si la póliza fue eliminada, el servidor responde 500 por la llave foránea. La suma de los porcentajes de una misma póliza debe ser 100%.
